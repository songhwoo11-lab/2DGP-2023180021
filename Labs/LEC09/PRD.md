# LEC09 애니메이션 뷰어 PRD

## 1. 목적 및 범위

`sonic-sprite.png`의 캐릭터 애니메이션을 모두 찾아 순서대로 재생하는 뷰어를 만든다.

- 언어 및 라이브러리: Python, `pico2d`
- 구현 파일: `sonic_animation_viewer.py` 한 개
- 스프라이트 시트: `sonic-sprite.png` (399×525)
- 제목, 로고, 크레딧 등 장식 이미지는 재생 대상에서 제외한다.

## 2. 스프라이트 시트 및 프레임 사양

## 3. 재생 및 화면 동작

- 모든 프레임을 원본 크기의 4배로 표시한다.
- 게임 화면은 너비:높이 **3:4** 비율로 설정한다. 프레임 사양을 조사한 뒤 최대 프레임과 4배 확대를 기준으로 창 크기를 산출한다. 제자리 동작의 프레임과 동작 이름이 잘리지 않도록 여백을 확보한다.
- **제자리 동작:** 화면 중앙에 고정해 재생한다.
- **이동 동작:** 동작 시작 시 화면 왼쪽에서 출발해 오른쪽으로 이동한다. 화면 오른쪽 밖으로 나가면 위치만 왼쪽 시작 위치로 되돌려 이동을 이어간다. 재진입할 때 프레임은 처음으로 초기화하지 않고 다음 프레임부터 계속하며, 해당 동작의 5회 반복 진행 상태도 유지한다.
- 이동 동작은 한 동작이 끝나고 다음 동작이 시작될 때 왼쪽 시작 위치로 초기화한다. 5회 반복 사이에는 위치를 초기화하지 않는다.
- 현재 동작 이름을 화면 왼쪽 위에 표시한다.
- 동작 목록 순서대로 각 동작을 5회 반복한 뒤 1초간 정지한다. 마지막 동작 뒤에는 첫 동작으로 돌아가 전체 순서를 반복한다.
- `ESC` 키를 누르면 프로그램과 사용 자원을 정상 종료한다.

## 4. 개발 단계 및 커밋

각 단계를 구현·확인한 뒤 해당 제목으로 커밋한다. 총 20회 이상 커밋하고, 모든 커밋 제목은 `LEC09: `로 시작한다.

1. `LEC09: 개발 요구사항과 완료 기준 정리` — 이 문서의 기능 범위와 검증 기준을 확정한다.
2. `LEC09: 스프라이트 시트 구성 조사` — 캐릭터 행과 장식 영역을 구분하고 동작 후보를 파악한다.
3. `LEC09: 애니메이션 동작 목록 작성` — 모든 동작의 이름과 재생 순서를 정한다.
4. `LEC09: 프레임 경계 및 좌표 측정` — 각 동작의 프레임별 `(x, y, 너비, 높이)`를 시트에서 측정한다.
5. `LEC09: 프레임 수와 크기 사양 기록` — 모든 동작의 프레임 수·크기를 표로 작성하고 크기 차이도 기록한다.
6. `LEC09: 뷰어 실행 파일 기본 구조 작성` — 단일 Python 파일과 실행 진입점을 구성한다.
7. `LEC09: pico2d 창 생성 및 이벤트 처리` — 창 초기화와 이벤트 처리 흐름을 구현한다.
8. `LEC09: 스프라이트 시트 로딩` — 실행 파일 기준으로 시트를 불러온다.
9. `LEC09: 3대4 화면 크기 산출` — 최대 프레임, 4배 확대와 UI 여백을 고려해 잘리지 않는 창 크기를 정한다.
10. `LEC09: 단일 프레임 중앙 출력` — 지정 프레임을 중앙에 표시하는 기본 출력을 구현한다.
11. `LEC09: 프레임 4배 확대 적용` — 원본 프레임 크기에 확대 배율을 적용한다.
12. `LEC09: 전체 동작 프레임 데이터 등록` — 측정한 좌표와 크기로 모든 애니메이션 프레임을 등록한다.
13. `LEC09: 동작별 이동 여부 설정` — 동작을 이동 또는 제자리로 분류한다.
14. `LEC09: 시간 기반 프레임 재생 구현` — 시간 간격에 따라 프레임을 갱신한다.
15. `LEC09: 동작별 5회 반복 및 1초 대기 구현` — 반복 횟수와 동작 사이 정지 시간을 적용한다.
16. `LEC09: 현재 동작 이름 출력` — 재생 중인 동작 이름을 왼쪽 위에 표시한다.
17. `LEC09: 제자리 동작 중앙 정렬` — 제자리 동작을 재생 내내 화면 중앙에 고정한다.
18. `LEC09: 이동 동작 좌우 이동 구현` — 이동 동작을 왼쪽에서 시작해 오른쪽으로 이동시킨다.
19. `LEC09: 화면 밖 재진입 상태 유지` — 화면 밖으로 나가면 위치만 되돌리고 프레임과 반복 진행은 이어간다.
20. `LEC09: 다음 이동 동작 시작 위치 초기화` — 새 이동 동작 시작 시에만 왼쪽 위치로 초기화한다.
21. `LEC09: 전체 동작 순환 구현` — 마지막 동작 다음에 첫 동작부터 재생한다.
22. `LEC09: ESC 종료 및 자원 정리` — 입력 시 재생을 끝내고 창과 이미지 자원을 정리한다.
23. `LEC09: 전체 재생과 완료 기준 검증` — 모든 동작을 재생해 프레임, 위치, 반복, 순환, 종료 및 잘림을 확인하고 수정한다.

## 5. 완료 기준

- 시트에 있는 모든 캐릭터 동작이 등록되어 있고 장식 이미지는 재생되지 않는다.
- 프레임 사양 표에 동작별 프레임 수와 실제 프레임 크기가 기록되어 있으며, 크기가 다른 프레임도 빠짐없이 명시되어 있다.
- 화면 비율은 3:4이며, 제자리 동작은 중앙에 표시되고 프레임과 동작 이름이 잘리지 않는다.
- 이동 동작은 왼쪽에서 오른쪽으로 이동한다. 화면 밖 재진입 시 위치만 초기화되고 프레임 순서와 반복 횟수는 이어진다.
- 각 동작은 5회 반복되고 다음 동작 전 1초 정지하며, 전체 순서가 반복된다.
- `ESC` 입력으로 프로그램이 정상 종료된다.
