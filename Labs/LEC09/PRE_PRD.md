# 요구사항 
- 도구와 파일	
> 사용할 프로그래밍 언어: Python   
> 사용할 모듈: pico2d   
> 구현 파일(단일): sonic_animation_viewer.py   
> 사용할 애니메이션 시트: sonic-sprite.png   
- 재생
> 이미지의 모든 동작을 원본 크기의 4배로 표시   
> 이미지는 항상 중앙에 그리기   
- 전환	
> 동작별 5회 반복 후 1초 정지   
> 다음 동작으로 전환   
> 어떤 동작인지 좌측 상단에 표시   
- 전체 순환	
> 마지막 동작 뒤 첫 동작부터 다시 재생   
> ESC 누르면 프로그램 종료   
- 개발 과정	
> 단계별 구현과 커밋을 반복해 최소 20회 커밋    
> 커밋 제목에 "LEC09: " 붙이면서 커밋 내용을 나타내는 제목 붙이기
